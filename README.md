# 📊 Дипломный проект: Аналитика онлайн-маркетплейса

Полный цикл настройки аналитики с нуля: от сбора данных по API до построения BI-дашбордов и формирования бизнес-рекомендаций по оптимизации ассортиментной матрицы и увеличению LTV клиентской базы.

## 🛠 Технологический стек
- **Инфраструктура**: Ubuntu 22.04, Docker, Docker Compose
- **База данных**: PostgreSQL 15
- **ETL/Скрипты**: Python 3.10, `requests`, `pandas`, `SQLAlchemy`
- **BI-визуализация**: Metabase
- **Планировщик**: Cron (ежедневный запуск в 07:00)
- **Аналитика**: ABC/XYZ-анализ, RFM-сегментация, расчет LTV

## 🚀 Как запустить проект
1. Разверните инфраструктуру: `docker compose up -d`
2. Установите зависимости: `pip install -r requirements.txt`
3. Загрузите исторические данные: `python scripts/fetch_data.py backfill`
4. Запустите аналитические скрипты для генерации отчетов.
